about=
    AI Agent by TerraLab is an AI agent for QGIS. It works on your own layers, in the project you already have open, and shows each step as it goes.

    • 253 tools: load and inspect data, style and label maps, run Processing algorithms, edit geometry, build print layouts

    • 73 open data connectors: OpenStreetMap, Copernicus, NASA, USGS, IGN, Overture, Planetary Computer and 66 more

    • A catalog of 843 ready datasets, from national sources in 174 countries and from EU-wide and global ones, each with its licence

    • You stay in control: you see every step before it runs, changes wait for your approval, and one click undoes anything it changed

    • Fits your habits: one conversation per project, and attach files, layers, selections or the map view to a message

    • Free tier, no card. Plans and limits: https://terra-lab.ai/pricing

    • QGIS 3.28 to QGIS 4, on Windows, macOS and Linux

    • Works with AI Edit and AI Segmentation when those TerraLab plugins are installed

    • 12 languages: English, French, Spanish, Portuguese, German, Italian, Dutch, Polish, Indonesian, Japanese, Chinese (simplified and traditional)

    • Answers come from an AI model. It can be wrong; review what it changes

    • Sends your request and a description of the open project to agent.terra-lab.ai, in the European Union. Your layers and files stay on your machine. See https://terra-lab.ai/privacy-policy

    - Connects faster and keeps working when a server address fails; place searches answer quicker
    - Code from the agent asks before riskier steps; KMZ files and the Area of interest stay intact

    - Questions come one at a time: pick an option or write your own answer, then send them together
    - Answers show clean tables, figures and short charts; memory notes save at once, with Undo
    - Data sources on one page with logos; AI Segmentation and AI Edit runs show their zone before paying
    - Processing run from code no longer freezes QGIS and Stop ends it; Pro chats survive a restart

    - Safer sign-in: the key reaches only the QGIS that started it, with a 6-character code as backup
    - QGIS stays responsive while rasters are read over the network, and the plugin starts faster
    - Over 60 new open data sources; WFS 1.1.0, folder layers, raster ZIPs and OGC API boxes load
    - Watersheds, grouped statistics and distances in metres come out right; menu dialogs never hang
