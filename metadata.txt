about=
    It works on your own layers, in the project you already have open, and shows each step as it goes.

    • 285+ tools: load and inspect data, style and label maps, run Processing algorithms, edit geometry, build print layouts

    • 60 open data connectors: OpenStreetMap, Copernicus, NASA, USGS, IGN, Overture, Planetary Computer and 53 more

    • A catalog of 530+ ready datasets, from national sources in 97 countries and from EU-wide and global ones, each with its licence

    • You stay in control: you see every step before it runs, changes wait for your approval, and one click undoes anything it changed

    • Fits your habits: one conversation per project, and attach files, layers, selections or the map view to a message

    • Works with AI Edit and AI Segmentation when those TerraLab plugins are installed

    • 12 languages: English, French, Spanish, Portuguese, German, Italian, Dutch, Polish, Indonesian, Japanese, Chinese (simplified and traditional)

    • Answers come from an AI model. It can be wrong; review what it changes

    • Sends your request and a description of the open project to agent.terra-lab.ai, in the European Union. Your layers and files stay on your machine. See https://terra-lab.ai/privacy-policy

changelog=
    1.5.0
    - Type while the agent works: a message waits in a queue or reaches the run at its next step
    - Edit your last message, or Undo and retry a failed run; a stopped run keeps its Undo
    - Each layer the agent adds keeps its source, licence and the step that made it in its metadata
    - QGIS calls you back when a run ends or waits for you; a QGIS 3.44 crash and several freezes fixed

    1.4.1
    - Loads are never refused or questioned for their number of features
    - Fewer approval cards for code that only reads the project
    - Raster styles keep a typed min and max; Paris open data and Planetary Computer imagery work again
    - Clipping Overture data to a country or city is faster

    1.4.0
    - Attach any file up to 200 MB (PDF, Word, Excel, text); a run can end with an HTML report you keep
    - A library of 46 guided examples with pictures, and a Data sources page for every connector
    - Fewer approval cards: Autopilot runs Python on its own, and calls waiting together share one card
    - Going back keeps your own unsaved edits; faster start-up, and Windows text and paths no longer cut

    1.3.2
    - A short connection drop (under 15 s) no longer shows a warning; the run keeps going
    - Filtered OpenStreetMap and Overture downloads fetch only matches; districts come as polygons
    - Run SQL in the database behind a saved connection; web layers no longer freeze QGIS
    - A CSV with no CRS lands in the right place; a fetched box area is no longer quoted as the data's

    1.3.1
    - Save a chain of steps as a Graphical Modeler model, or package a whole project as one GeoPackage
    - A clip to a country or city keeps only what lies inside; a WFS link with no layer name still loads
    - The chat never grows wider than the panel, and approval cards say which files change on disk
    - Code the agent runs asks for approval only when it changes files or the project; it runs on QGIS 4
